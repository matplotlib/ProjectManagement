### macOS Font Bug on 3.11

Some users are reporting an exception on macOS 27 when building the font cache. [#32453](https://github.com/matplotlib/matplotlib/pull/32453) is a bandaid fix for 3.11.x as this issue is fixed "properly" in 3.12.

### single row/color mesh 
- defining that an edge case related to nearest shading that raises an error that suggests that users use cell edges if that's what they're trying to do
    - currently silently fails with no plot
- automagically trying to guess what to do is too complicated b/c data can be unitized/arbitrary
    - there's an issue to allow for mixed modes -> e.g. columns as centers, rows as boundaries
consensus: raise an error for these edge cases

### nanobind/freethreaded support
- nanobind would be replacing pybind11
    - would change the release workflow 
    - faster compilation
    - smaller release size
- nano bind has a split mode that will take care of permutations of the python ABI
- nanobind doesn't support 3.14t and wasm
    - would need to build this seperatly and bundle w/ nanobind
- nanobind doesn't support subinterpretors 
    - numpy currently does not support subinterpretors (unknown for rest of stack)
    - numpy planning to support eventually
- freethreaded python:
    - freethread support in 3.13 was experimental, removed that support in CI build wheel version 4 
    - 3.14t freethreaded was stable
    - python requires opting into choosing the freethreaded {version}t version
    - 3.14t can be handled in meson

consensus: @QuLogic, @ksunden, and @iccir working towards nanobind transition

### remove backend param from rcParams

- step 1: moves backend from rcParams dict and makes it an rcParams class attribute, global state so can only exist once, 
- step 2: term is to move it out from rcParams
    - would deprecate the [] usage
- step 3: deprecating backend
    - do we need alternative or will `MPLBACKEND` environment variable be good enough
